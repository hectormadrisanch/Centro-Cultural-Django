# Plataforma de Gestión de Centro Cultural

Aplicación web desarrollada con Django para la gestión de actividades, usuarios, monitores y salas de un centro cultural municipal.

## Requisitos
* Python 3.12+
* Django 5.0+

## Instrucciones de instalación
1. Clonar el repositorio.
2. Activar el entorno virtual: `source .venv/bin/activate` (Linux/Mac) o `.venv\Scripts\activate` (Windows).
3. Instalar dependencias: `pip install django`
4. Aplicar migraciones: `python manage.py migrate`
5. Arrancar el servidor: `python manage.py runserver`
